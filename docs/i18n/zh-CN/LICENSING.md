```

设计本身生活在 `models/` 且由第1节涵盖.

下面是: **没有** 覆盖的 Robonine 版权在上面. 他们是
来自上游的 SO-ARM100/SO-ARM101 项目 TheRobotStudio 和是

```

上游 SO-ARM101 手腕几何 Robonine's `RB9.01.062.010 Main frame`.
在它作为两个独立的网格重新出口之前,整个文件都被分配
下面 Apache-2.0: Robonine 无法授予 CERN-OHL-P-2.0 在几何学上,它没有
免费授权自己的部分 Apache-2.0. 同样的几何
在下列单独可使用: CERN-OHL-P-2.0 作为
`models/parts/RB9.01.062.010 Main frame.STL`.

`community/histology-slide-gripper/mujoco/meshes/arm/*.stl` 是字节相同的
的副本 `simulation/so_arm_101_description/meshes/visual/*.stl` 和继承
它们的许可从那里 ⁇ ,所以这八份文件中的六份是上游材料,
没有 Robonine是工作.

`community/histology-slide-gripper/` 由迈克尔·维亚切斯拉夫 (Michael Viacheslavov) 提供
([没有任何问题.](https://github.com/histochemichael)) ,并获得许可
同样的三方分类;版权由其作者拥有.

看看 [`simulation/so_arm_101_description/meshes/LICENSE.md`](simulation/so_arm_101_description/meshes/LICENSE.md)
对于该目录的每档次分类.
