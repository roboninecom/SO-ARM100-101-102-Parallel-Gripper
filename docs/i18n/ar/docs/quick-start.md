# دليل البدء السريع

أحضروا مصابكم المتابع SO-ARM101 ! صعداً ويركضون

[![SO-ARM101 قابض متوازٍ](../../../../assets/images/SO%20ARM%20101%20Parallel%20Gripper%20Live.jpg)](https://youtube.com/shorts/bSyXjgNGXZk)

*انقر على الصورة [شاهدوا المقبض في العمل](https://youtube.com/shorts/bSyXjgNGXZk)!*

<a id="what-youll-need"></a>
## ما ستحتاجه

<a id="step-1-3d-print-the-parts-2-4-hours"></a>
## خطوة1: 3D طباعة الأجزاء (2-4الساعات)

1. تحميل ملفات STL من `models/parts/`
2. الطباعة مع الإعدادات الموصى بها:
   - ارتفاع الطبقة: 0.2mm
   - المكملات: 20٪ (الهيكل/المضغوطات) ، 100٪ (التعدين)
   - المواد: PLA أو PETG
3. إزالة الدعم

![لوحة الاختبار](../../../../assets/images/assembly/rod-test-plate.PNG)

للتأكد من أن العصا التي تشتريها تناسب بشكل أفضل في المقبضات، تحتاج إلى استخدام قطعة اختبارية. طبعها و، من أكبر ثقب إلى أصغر، اختر قطر يسمح للصلب بالانضمام إلى جزء التجربة دون صعوبة وبحد أدنى من المدى. ثم طباعة المقبضات بنفس قطر الثقب الذي ذكر في اسم ملف stl (مثل RB9.01.062.021 (D6.1) إذا اخترت قطر 6.1 mm).

**طابعات 3D متوافقة** (180 × 180mm + سرير):
- المختبر البامبو A1 ميني
- بروسا ميني / ميني+
- كوبرا نيو أي كوبيك
- أي طابعة ذات السرير ≥180×180mm

**أجزاء للطباعة:**
- 1x الهيكل الرئيسي (RB9.01.062.010)
- 2x فك التثبيت (RB9.01.062.020)
- 2x جريدة مسننة (RB9.01.062.030)
- 1x ترس (RB9.01.062.040)
- 1x حامل الكاميرا (RB9.01.060.074)
- 1x حامل (RB9.01.060.080)
- 1x مباعد الكاميرا (RB9.01.060.090)

<a id="step-3-assembly-30-45-minutes"></a>
## خطوة3التجميع (30-45الدقائق)

اتبع التفاصيل [دليل الجمعية](assembly-guide.md):


1. إدراج كابل الخدمة
2. استخدام Feetech البرنامج تحريك الخادم إلى موقعها الحد الأدنى (تحرك المنزلق في البرنامج إلى اليسار)
3. ثبّت الجرائد المسننة في فكوك التثبيت
4. أدخل قضبان التوجيه في كلا الفكين
5. ركّب المحامل في الهيكل الرئيسي وثبّتها بالبراغي
6. ثبّت قضبان التوجيه في الهيكل بالضغط
7. حرّك الفكين إلى أقصى اليسار وأقصى اليمين
8. ادخل الخادم واصليها بالشواشف
9. ربط الكاميرا spacer وكاميرا UVC ، معالجة مع المسامير 4x والمكسرات M2 (اختياري)
10. الجمع إلى ذراع الروبوت (اختياري)

---

<a id="step-4-software-setup-10-minutes"></a>
## خطوة4: إعداد البرمجيات (10الدقائق)

1. **التثبيت STServo SDK**
   ```bash
   git clone https://github.com/FEETECH-RC/STServo_SDK_Python.git
   cd STServo_SDK_Python
   cp -r STservo_sdk /path/to/your/project/
   ```

2. **التثبيت Python الاعتمادات**
   ```bash
   pip install pyserial
   ```

3. **إعداد الاتصال**
   ```python
   DEVICENAME = 'COM7'  # Windows
   # DEVICENAME = '/dev/ttyUSB0'  # Linux
   STS_ID = 1  # Servo ID (use 6 if connected as gripper on SO-ARM101)
   ```

---

<a id="step-5-first-test-5-minutes"></a>
## خطوة5: الاختبار الأول (5الدقائق)

1. **قم بتوصيل الأجهزة**
   - جهاز إصلاح الحافلة
   - أداة تحويل الحافلات إلى الكمبيوتر (USB)
   - إمدادات الطاقة (6-12 فولت، دقيقه 3 أ)

2. **إجراء اختبار أساسي**
   ```bash
   cd software/python
   python gripper_control.py
   ```

3. **جرب الأوامر الأساسية**
   - أدخل `45` لفتح القابض
   - أدخل `-45` لإغلاق القابض
   - أدخل `0` إلى المركز
   - اضغط على إدخال للخروج

<a id="troubleshooting"></a>
## حل المشاكل

<a id="connection-issues"></a>
### قضايا الاتصال
- ✅ تحقق من منفذ COM في مدير الأجهزة (Windows) أو `ls /dev/ttyUSB*` (لينكس)
- ✅ التحقق من ان الايل دي للكهرباء المنزلية تعمل
- ✅ حاول معدلات البود المختلفة (المعياري: 1000000)
- ✅ تحقق من اتصالات الكابل

<a id="movement-issues"></a>
### قضايا الحركة
- ✅ التحقق من إشراك الأدوات مع الرف
- ✅ التحقق من الارتباط الميكانيكي
- ✅ تأكد من حركة العدوى بحرية على العصي
- ✅ مراقبة درجة حرارة الخدمة (ماكس 60°C)

<a id="software-issues"></a>
### مشاكل البرمجيات
- ✅ التثبيت STServo SDK بشكل صحيح
- ✅ التحقق Python الإصدار (3.6+)
- ✅ التحقق من الإذنات للميناء المتسلسل: `sudo chmod 666 /dev/ttyUSB0` (لينكس)
