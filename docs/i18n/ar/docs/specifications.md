# SO ARM 100/101 مقبض متوازي

<a id="overview"></a>
## الرؤية العامة

الجهاز النهائي الضوئي المطبوع 3D المصمم من: **Robonine** للبرنامج الروبوتي التلفزيوني المفتوح المصدر SO ARM 100/101. توفر هذه الآلية حركة متوازية موثوقة في الفك و قوة قبض كافية لمجموعة واسعة من التطبيقات التعليمية والتجريبية.

![ضغط التابعة مثبت على SO-ARM100](../../../../assets/images/specification/07-gripper-on-so-arm100.jpg)

*ضغط التابعة مثبت على SO-ARM100 ذراع الروبوت*

<a id="key-features"></a>
## الميزات الرئيسية

- تصميم المصدر المفتوح
- تكلفة الـ BOM للاشتباك الواحد: ~$50
- يمكن طباعتها خلال دورة واحدة على طابعة 3D FDM ذات مستوى استهلاك
- متوافق مع الكاميرات الفيديو الشعبية:
  - Orbbec التوأم 2
  - RealSense D405, D435/D435i, D455
  - GC2093 2MP كاميرا USB
  - IMX335 كاميرا USB 5MP

<a id="camera-compatibility"></a>
## التوافق مع الكاميرا

يتماشى قبضة Follower مع مختلف الكاميرات عبر حامل الكاميرا المقابل.

![كاميرات مختلفة مثبتة على المقبض](../../../../assets/images/specification/09-camera-types.png)

*الكاميرات المختلفة المتجهة إلى الوقود (من اليسار إلى اليمين): RealSense، وحدات الكاميرا USB Orbbec التوأم 2*

<a id="supported-cameras"></a>
### الكاميرات المدعومة

| الكاميرا | النوع | الملاحظات |
|--------|------|-------|
| IMX335 5MP USB | الـ RGB | رقيقة ومنخفضة التكلفة |
| GC2093 USB 2MP | الـ RGB | خيار الميزانية |
| Orbbec التوأم 2 | RGB-D | استشعار العمق |
| RealSense D405 | RGB-D | عمق على نطاق قريب |
| RealSense D435/D435i | RGB-D | الغرض العام |
| RealSense D455 | RGB-D | عمق طويل المدى |

<a id="supplied-resources"></a>
## الموارد المقدمة

- مجموعة كاملة من ملفات STL للطباعة 3D
- دليل التجميع
- الرسومات ذات أبعاد التثبيت
- ملف URDF للمحاكاة الروبوتية

---

<a id="integration"></a>
## التكامل

يمكن دمج المقبض بشكل مستقل في العديد من الأنظمة الروبوتية بفضل تثبيته السهل والسهل عبر فلنج التثبيت القياسي.

<a id="mounting-requirements"></a>
### المتطلبات المتزايدة

- 4x M3 المسامير للاصطلاح بالفلانج
- متوافقة مع SO-ARM100/101 ذراع الروبوت
- لوحة مُعدّلة مُخصصة متاحة لذراع الروبوتات الأخرى

<a id="communication"></a>
### التواصل

- الاتصال المتسلسل عبر TTL أو RS485
- سرعة البود: ما يصل إلى 1 ميغابت/س
- البروتوكول: Feetech بروتوكول STS
