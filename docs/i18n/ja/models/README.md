# 3Dモデル

このフォルダには,フォローアグリッパーの組み立てのための STL ファイルが含まれています.

<a id="complete-assembly"></a>
## 完全な集会

| ファイル | 記述 | 互換性のあるプリンター |
|------|-------------|---------------------|
| `Follower gripper (165x165 bed size).STL` | 完全なグリッパー部品セット | 床サイズ > 165×165mm のプリンター |

<a id="compatible-3d-printers"></a>
### 互換性のある3Dプリンター

- **バンボラボ A1 ミニ** (180×180×180mm)
- **プロサ・ミニ / ミニ+** (180×180×180mm)
- **クリアリティ エンダー-2 プロ** (165×165×180mm)
- **アニキュビック・コブラ・ネオ** (長さ220×220×250mm)
- **砲兵の天才** (長さ220×220×250mm)

*注: ベッドサイズ ≥165×165mmのプリンターは,完全な組み立てプレビューをプリントすることができます.*

<a id="print-settings"></a>
## プリント設定

| パラメーター | 推奨値 |
|-----------|-------------------|
| 材料 | PLA / PETG |
| 層の高さ | 0.2mm (0.15mm ギア向け) |
| 充填する | 20% (30%ギアについて) |
| サポート | 必要に応じて |
| 壁 | 3-4周辺 |

<a id="notes"></a>
## 注記

- より強い力のために,より高い充填 (100%) の印刷ギア
- メインフレームは方向に応じてサポートが必要かもしれません
- 後処理: ローヤリングフィットに軽い砂利が必要になる
- 各パーツは標準的なFDMプリンターで印刷できます

<a id="better-rods-fit"></a>
## より良い棒が合う
![テストプレート](../../../../assets/images/assembly/rod-test-plate.PNG)

クランプによりよく収まるために 試用品を使わなければなりません 印刷して,最大から最小まで作業して,棒がテスト部品に簡単に収まるようにする直径を選択します. その後, stlファイル名 (例えば, RB9.01.062.021 (D6.1) もし直径 6.1 mm を選択した場合.
