- **Цены** по состоянию на январь 2026 г. являются приблизительными и основываются на списках Amazon/поставщиков
- **Крупные сбережения**: Прикрепления и подшипники поставляются в упаковке, обеспечивая дополнительные средства для будущих построек

- **Погрузка** не включены в оценки
- Подумайте о заказах у одних поставщиков для снижения расходов на доставку
