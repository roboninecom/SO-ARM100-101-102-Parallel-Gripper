# SO ARM 100/101 Параллельный следящий захват

<a id="overview"></a>
## Обзор

Легкий 3D-печатный конечный эффект, разработанный **Robonine** для открытого исходного кода телеоперационной роботизированной платформы SO ARM 100/101. Механизм обеспечивает надежное параллельное движение челюсти и достаточную удерживающую силу для широкого спектра образовательных и экспериментальных применений.

![Зацепка подсоединителя установлена SO-ARM100](../../../../assets/images/specification/07-gripper-on-so-arm100.jpg)

*Зацепка подсоединителя установлена SO-ARM100 роботская рука*

<a id="key-features"></a>
## Ключевые особенности

- Дизайн с открытым исходным кодом
- Стоимость BOM на один прицеп: ~ $50
- Может быть напечатан в течение одного цикла на потребительском 3D-принтере FDM
- Совместимо с популярными видеокамерами:
  - Orbbec Близнецы 2
  - RealSense D405, D435/D435i, D455
  - GC2093 2MP модуль камеры USB
  - IMX335 5MP Камера USB

<a id="integration"></a>
## Интеграция

Захват может быть независимо интегрирован в многочисленные роботизированные системы благодаря его удобной и простой установке с помощью стандартного монтажного фланжа.

<a id="mounting-requirements"></a>
### Увеличение требований

- 4x-шрубы M3 для прикрепления к фланге
- Совместимость с SO-ARM100/101 роботская рука
- Размещаемые для других роботовых рук индивидуальные пласты адаптера

<a id="communication"></a>
### Сообщение

- Серийная связь через TTL или RS485
- Скорость Baud: до 1 Мбит/с
- Протокол: Feetech Протокол СТС
