# Быстрое руководство по запуску

Принеси свой Захват для последователей SO-ARM101 Вверх и бегом!

[![SO-ARM101 Параллельный захват](../../../../assets/images/SO%20ARM%20101%20Parallel%20Gripper%20Live.jpg)](https://youtube.com/shorts/bSyXjgNGXZk)

*Нажмите на изображение [посмотреть работу захвата](https://youtube.com/shorts/bSyXjgNGXZk)!*

<a id="what-youll-need"></a>
## Что тебе понадобится

<a id="hardware"></a>
### Оборудование
- [ ] Все 3D-печатные части (см. [3D-модели](../models/README.md))
- [ ] Электронные компоненты (см. [БОМ](bom.md))
- [ ] Механические компоненты (подшипники, направляющие, крепёж)
- [ ] Инструменты: крестовая отвёртка PH1, шестигранные ключи M2 (H1.5) и M4 (H2.5)

<a id="software"></a>
### Программное обеспечение
- [ ] Python 3.6+ установлены
- [ ] STServo Скачать SDK
- [ ] Имеющийся SO-ARM100/101 контроллер, USB-соединение и питание рук

<a id="step-1-3d-print-the-parts-2-4-hours"></a>
## Шаг 1: 3D-печать деталей (2-4 часа)

1. Загрузить файлы STL из `models/parts/`
2. Печать с рекомендуемыми настройками:
   - Высота слоя:0.2Мм
   - Заполнение: 20% (рама/зажимы), 100% (шестерни)
   - Материал: PLA или PETG
3. Удалить опоры

![Испытательная плита](../../../../assets/images/assembly/rod-test-plate.PNG)

Чтобы подобрать посадку купленных направляющих в зажимах, используйте тестовую деталь. Напечатайте тестовую деталь и, начиная с самого большого отверстия, подберите диаметр, при котором направляющая входит без усилия и с минимальным зазором. Затем напечатайте зажимы с выбранным диаметром отверстия, указанным в имени STL-файла (например, RB9.01.062.021 (D6.1) если вы выбрали диаметр6.1Мм).

**Совместимые 3D-принтеры** (180×180 мм + постель):
- Лаборатория бамбу А1 мини
- Проса MINI / MINI+
- Anycubic Kobra Neo
- Любой принтер с кроватью ≥180×180 мм

**Части для печати:**
- 1x Основная рама (RB9.01.062.010)
- 2x Зажим (RB9.01.062.020)
- 2x Зубчатая рейка (RB9.01.062.030)
- 1x Шестерня (RB9.01.062.040)
- 1x Держатель камеры (RB9.01.060.074)
- 1x Держатель (RB9.01.060.080)
- 1x Проставка камеры (RB9.01.060.090)

<a id="step-2-gather-components-1-2-days-shipping"></a>
## Шаг 2: Сбор компонентов (1-2 дня доставки)

Заказать части из [Сборник материалов](bom.md). Повторное использование контроллера рук и питания; они не соответствуют стоимости прицепки:

| Компонент | КТИ | Восточная. Стоимость |
|-----------|:---:|-----------|
| Feetech STS3215 серво | 1 | ~$29 |
| MF106ZZ подшипники (10х6х3 мм) | 2 | ~$2 |
| Алюминиевые/углеродные трубы D6x1x125 мм | 2 | ~$4 |
| 3D-печать PLA| 8 частей | ~$12 |
| Крепёж (винты и гайки M2/M4) | различные | ~$3 |

**Общая предполагаемая стоимость: ~$50**

<a id="step-3-assembly-30-45-minutes"></a>
## Шаг 3: сборка (30-45 минут)

Следуйте подробным указаниям [Руководство по собранию](assembly-guide.md):


1. Вставить сервокабель
2. Использование Feetech Программное обеспечение перемещает серво на минимальное положение (переместить пластинку в программном обеспечении влево)
3. Прикрепите зубчатые рейки к зажимам
4. Вставьте направляющие стержни в оба зажима
5. Установите подшипники в основную раму и закрепите винтами
6. Защёлкните направляющие стержни в раме
7. Разведите зажимы в крайние левое и правое положения
8. Установите сервопривод и закрепите винтами
9. Установите проставку и UVC-камеру; используйте 4x винта и гайки M2 (необязательно)
10. Установите на манипулятор (необязательно)

---

<a id="step-4-software-setup-10-minutes"></a>
## Шаг 4: Настройка программного обеспечения (10 минут)

1. **Установка STServo SDK**
   ```bash
   git clone https://github.com/FEETECH-RC/STServo_SDK_Python.git
   cd STServo_SDK_Python
   cp -r STservo_sdk /path/to/your/project/
   ```

2. **Установка Python зависимости**
   ```bash
   pip install pyserial
   ```

3. **Настройка соединения**
   ```python
   DEVICENAME = 'COM7'  # Windows
   # DEVICENAME = '/dev/ttyUSB0'  # Linux
   STS_ID = 1  # Servo ID (use 6 if connected as gripper on SO-ARM101)
   ```

---

<a id="step-5-first-test-5-minutes"></a>
## Шаг 5: Первый тест (5 минут)

1. **Подключить оборудование**
   - Сцепление серво → серво No5 на SO-ARM101 сервошина
   - Имеющийся контроллер манипулятора → компьютер (USB)
   - Используйте блок питания манипулятора, настроенный для установленных сервоприводов
   - Задайте сервоприводу захвата ID, соответствующий `STS_ID` и убедитесь, что он уникален на шине
   - Перед открытием последовательного порта закройте другие программы управления роботом

2. **Провести базовый тест**
   ```bash
   cd software/python
   python gripper_control.py
   ```

3. **Попробуйте основные команды**
   - Войти . `45` для открытия захвата
   - Войти . `-45` для закрытия захвата
   - Войти . `0` в центре
   - Нажмите "Ввести" для выхода

<a id="troubleshooting"></a>
## Устранение неполадок

<a id="connection-issues"></a>
### Вопросы связи
- ✅ Проверьте порт COM в Управляющем устройствах (Windows) или `ls /dev/ttyUSB*` (Linux)
- ✅ Убедитесь , что сервоприводный светодиод включен
- ✅ Попробуйте различные скорости baud (по умолчанию: 1000000)
- ✅ Проверьте кабельные соединения

<a id="movement-issues"></a>
### Вопросы передвижения
- ✅ Проверьте зацепление шестерни с рейкой
- ✅ Убедитесь, что механизм не заклинивает
- ✅ Убедитесь, что подшипники свободно перемещаются по направляющим
- ✅ Контроль температуры серво (максимум 60°C)

<a id="software-issues"></a>
### Проблемы с программным обеспечением
- ✅ Установка STServo SDK правильно
- ✅ Проверка Python версия (3.6+)
- ✅ Проверьте разрешения серийного порта: `sudo chmod 666 /dev/ttyUSB0` (Linux)
