<a id="documentation-translations"></a>
# Переводы документации

Документация доступна на английском, русском, испанском, французском, немецком и бразильском языках
португальский, китайский в упрощенном виде, японский, хинди и арабский. Используйте языковые ссылки
в главном README или [Индекс языка](../../README.md).

<a id="scope-and-source-of-truth"></a>
## Объем и источник истины

Английские источники документов остаются на своих оригинальных путях. Полные переводы
`docs/i18n/<language>/` отражают структуру хранилища, включая аппаратные руководства;
примеры, изменения в сообществе, руководства по моделированию, инструкции по внесению взносов;
и объяснения лицензирования. Ссылки между переведенными документами остаются в выбранном
язык. CAD, код, конфигурация, изображения, видео, оригинальные PDF-файлы и юридическая лицензия
сообщения обмениваются. Текст, встроенный в существующие изображения и PDF-файлы, остается непереведенным.

Корень `NOTICE` является авторитетным для присвоения третьим лицам. Переводы
объяснения лицензирования являются информационными; преимущественным является оригинальный текст лицензии.

<a id="translation-status"></a>
## Статус перевода

Первоначальные переводы были созданы с помощью локальной модели перевода NLLB-200 и
ИИ-помощь, затем проверка на структуру документов, сохранение технических значений,
идентификаторы частей, блоки кодов, ссылки и якорь. Они не были рассмотрены
носители языка. Автоматические проверки не свидетельствуют о точности языка или оборудования.
Решение двусмысленных вопросов по английскому источнику и сообщение о проблемах с языком,
путь документа и затронутое предложение.

<a id="maintain-translations"></a>
## Сохранение переводов

1. Сначала изменить исходный английский, а затем обновить соответствующий документ в каждой
   язык. Сохранить все инструкции, предупреждения, таблицы, значения, идентификаторы деталей.
   команды и внешние URL-адреса.
2. Сохраняйте переведенные ссылки на документ на выбранном языке. Общие активы должны
   используют относительные пути обратно к существующим местоположениям хранилища. Сохранить ясные
   Английские идентификаторы якоря, так что ссылки раздела работают на языках.
3. После проверки перевода запишите его исходную версию с
   `python .github/scripts/check_translations.py --record-reviewed --locale ru --source docs/bom.md`.
   Эта команда записывает версию; она не переводит или не проверяет документ.
4. Беги . `python .github/scripts/check_translations.py` и
   `pre-commit run --all-files`. Укажите, на каких языках был проведен человеческий обзор в PR.

Добавить новые отслеживаемые документы Markdown `docs/i18n/manifest.json` с полным
перевод на каждый язык. Проверка использует отслеживаемые исходные файлы, так что локальные
неотследованные заметки не становятся требованиями к документации. Английский язык включен в
копию источника для последовательной навигации. Языковые теги следуют BCP 47.
