<a id="3d-models"></a>
# 3D-модели

Эта папка содержит файлы STL для сборки Follower Gripper.

<a id="complete-assembly"></a>
## Полное собрание

| Файл | Описание | Совместимые принтеры |
|------|-------------|---------------------|
| `Follower gripper (165x165 bed size).STL` | Полный комплект деталей крепления | Печатные устройства с размером постели > 165×165 мм |

<a id="compatible-3d-printers"></a>
### Совместимые 3D-принтеры

- **Лаборатория бамбу А1 мини** (180×180×180 мм)
- **Проса MINI / MINI+** (180×180×180 мм)
- **Креальность Ender-2 Pro** (165×165×180 мм)
- **Anycubic Kobra Neo** (220×220×250 мм)
- **Артиллерийский гений** (220×220×250 мм)

*Примечание: Любой принтер с размером постели ≥ 165×165 мм может напечатать полный предварительный экран сборки.*

<a id="print-settings"></a>
## Настройки печати

| Параметр | Рекомендуемая стоимость |
|-----------|-------------------|
| Материал | PLA / PETG |
| Высота слоя | 0.2Мм (0.15мм для передач) |
| Наполнение | 20% (30% для передач) |
| Поддержка | По мере необходимости |
| Стены | 3-4 периметра |

<a id="notes"></a>
## Примечания

- Печатные приборы с более высоким наполнением (100%) для повышения прочности
- Главная рамка может потребовать опоры в зависимости от ориентации
- Послеобработка: для подшипников может потребоваться легкая шлифовка
- Отдельные части могут быть напечатаны на любом стандартном принтере FDM

<a id="better-rods-fit"></a>
## Лучшие направляющие стержни .
![Испытательная плита](../../../../assets/images/assembly/rod-test-plate.PNG)

Чтобы подобрать посадку купленных направляющих в зажимах, используйте тестовую деталь. Напечатайте тестовую деталь и, начиная с самого большого отверстия, подберите диаметр, при котором направляющая входит без усилия и с минимальным зазором. Затем напечатайте зажимы с выбранным диаметром отверстия, указанным в имени STL-файла (например, RB9.01.062.021 (D6.1) если вы выбрали диаметр6.1Мм).
