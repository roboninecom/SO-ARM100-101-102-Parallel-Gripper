# SO ARM 100/101 समानांतर फॉलोअर ग्रिपर

<a id="overview"></a>
## अवलोकन

3D मुद्रित अंत प्रभावक **Robonine** ओपन-सोर्स टेलीऑपरेटिंग रोबोटिक प्लेटफॉर्म SO ARM 100/101 के लिए। तंत्र शैक्षिक और प्रयोगात्मक अनुप्रयोगों की एक विस्तृत श्रृंखला के लिए विश्वसनीय समानांतर जांघ आंदोलन और पर्याप्त पकड़ बल प्रदान करता है।

![फॉल्टर पकड़ पर लगाया गया SO-ARM100](../../../../assets/images/specification/07-gripper-on-so-arm100.jpg)

*फॉल्टर पकड़ पर लगाया गया SO-ARM100 रोबोट हाथ*

<a id="key-features"></a>
## मुख्य विशेषताएं

- ओपन सोर्स डिजाइन
- एक ग्रिपर की BOM लागतः ~$50
- उपभोक्ता-ग्रेड FDM 3D प्रिंटर पर एक चक्र के दौरान मुद्रित किया जा सकता है
- लोकप्रिय वीडियो कैमरों के साथ संगतः
  - Orbbec मिथुन 2
  - RealSense D405, D435/D435i, D455
  - GC2093 2MP यूएसबी कैमरा मॉड्यूल
  - IMX335 5MP यूएसबी कैमरा

*ग्रिपर पर लगाए गए विभिन्न कैमरे (बाएं से दाएं): RealSense, यूएसबी कैमरा मॉड्यूल, Orbbec मिथुन 2*

<a id="integration"></a>
## एकीकरण

स्टैंडर्ड माउंटिंग फ्लेंज के माध्यम से इसकी सुविधाजनक और सरल स्थापना के लिए धन्यवाद, ग्रिपर को स्वतंत्र रूप से कई रोबोटिक प्रणालियों में एकीकृत किया जा सकता है।

<a id="mounting-requirements"></a>
### बढ़ती आवश्यकताएँ

- फ्लैंज संलग्नक के लिए 4x M3 शिकंजा
- संगत SO-ARM100/101 रोबोट हाथ
- अन्य रोबोट हथियारों के लिए उपलब्ध कस्टम एडाप्टर प्लेटें

<a id="communication"></a>
### संचार

- TTL या RS485 के माध्यम से सीरियल कनेक्शन
- बाउड दरः 1 एमबीपीएस तक
- प्रोटोकॉलः Feetech एसटीएस प्रोटोकॉल
