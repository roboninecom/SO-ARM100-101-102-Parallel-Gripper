# त्वरित प्रारंभ गाइड

अपने अनुयायी ग्रिपर के लिए प्राप्त SO-ARM101 उठो और दौड़ो!

[![SO-ARM101 समानांतर ग्रिपर](../../../../assets/images/SO%20ARM%20101%20Parallel%20Gripper%20Live.jpg)](https://youtube.com/shorts/bSyXjgNGXZk)

*छवि पर क्लिक करें [पकड़ को कार्रवाई में देखें](https://youtube.com/shorts/bSyXjgNGXZk)!*

<a id="what-youll-need"></a>
## आपको क्या चाहिए

<a id="hardware"></a>
### हार्डवेयर
- [ ] सभी 3D मुद्रित भाग (देखें) [3 डी मॉडल](../models/README.md))
- [ ] इलेक्ट्रॉनिक घटक (देखें) [बीओएम](bom.md))
- [ ] यांत्रिक घटक (बेयरिंग, रॉड, फिक्स्चर)
- [ ] उपकरणः फिलिप्स स्क्रूड्राइवर PH1, हेक्स कुंजी M2 (H1.5) और M4 (H2.5)

<a id="software"></a>
### सॉफ्टवेयर
- [ ] Python 3.6+ स्थापित
- [ ] STServo SDK डाउनलोड किया गया
- [ ] विद्यमान SO-ARM100/101 नियंत्रक, यूएसबी कनेक्शन और हाथ बिजली की आपूर्ति

---

<a id="step-1-3d-print-the-parts-2-4-hours"></a>
## चरण 1: भागों को 3 डी प्रिंट करें (2-4 घंटे)

1. से STL फ़ाइलें डाउनलोड करें `models/parts/`
2. अनुशंसित सेटिंग्स के साथ प्रिंट करेंः
   - परत की ऊंचाईः 0.2 मिमी
   - भरनाः 20% (फ्रेम/क्लैंप), 100% (गियर)
   - सामग्रीः पीएलए या पीईटीजी
3. समर्थन हटाएं

![परीक्षण प्लेट](../../../../assets/images/assembly/rod-test-plate.PNG)

यह सुनिश्चित करने के लिए कि आपके द्वारा खरीदी जाने वाली छड़ें क्लैंप में बेहतर फिट हों, आपको एक परीक्षण टुकड़ा का उपयोग करना होगा। इसे प्रिंट करें और सबसे बड़े छेद से लेकर सबसे छोटे छेद तक काम करते हुए, उस व्यास का चयन करें जो छड़ी को परीक्षण भाग में आसानी से और न्यूनतम क्लियरेंस के साथ फिट होने की अनुमति देता है। फिर उसी छेद व्यास के साथ क्लैंप प्रिंट करें जो stl फ़ाइल नाम में उल्लेख किया गया है (जैसे RB9.01.062.021 (D6.1) यदि आप व्यास 6.1 मिमी चुनते हैं।

**संगत 3 डी प्रिंटर** (180×180 मिमी + बिस्तर):
- बाम्बू लैब ए1 मिनी
- Prusa MINI / MINI+
- एनीक्यूबिक कोबरा नीओ
- बिस्तर ≥180×180 मिमी वाला कोई भी प्रिंटर

**छापने के लिए भागः**
- 1x मुख्य ढाँचा (RB9.01.062.010)
- 2x जकड़ने वाला जबड़ा (RB9.01.062.020)
- 2x दांतेदार रैक (RB9.01.062.030)
- 1x गियर (RB9.01.062.040)
- 1x कैमरा धारक (RB9.01.060.074)
- 1x धारक (RB9.01.060.080)
- 1x कैमरा स्पेसर (RB9.01.060.090)

## चरण 2: घटकों को इकट्ठा करें (1-2 दिन शिपिंग)

ऑर्डर पार्ट्स [सामग्री का विवरण](bom.md). आर्म कंट्रोलर और पावर सप्लाई का पुनः उपयोग करें; ये ग्रिपर की लागत से बाहर हैंः

| घटक | Qty | एस्ट. लागत |
|-----------|:---:|-----------|
| Feetech STS3215 सर्वो | 1 | ~$29 |
| MF106ZZ बैग (10x6x3 मिमी) | 2 | ~$2 |
| एल्यूमीनियम/कार्बन ट्यूब D6x1x125 मिमी | 2 | ~$4 |
| 3डी प्रिंटिंग पीएलए| 8 भाग | ~$12 |
| फास्टनर (M2/M4 शिकंजा/नट) | विभिन्न | ~$3 |

**कुल अनुमानित लागतः ~$50**

<a id="step-3-assembly-30-45-minutes"></a>
## चरण 3: सभा (30-45 मिनट)

विवरण का पालन करें [विधानसभा गाइड](assembly-guide.md):


1. सर्वो केबल डालें
2. उपयोग करना Feetech सॉफ़्टवेयर सर्वो को अपनी न्यूनतम स्थिति में ले जाएं (सॉफ़्टवेयर में स्लाइडर को बाईं ओर ले जाएं)
3. दांतेदार रैक को जबड़ों से जोड़ें
4. गाइड छड़ों को दोनों जबड़ों में डालें
5. बेयरिंग को मुख्य ढाँचे में लगाएँ और स्क्रू से कसें
6. गाइड छड़ों को ढाँचे में बिठाएँ
7. जबड़ों को बाईं और दाईं अंतिम स्थितियों तक फैलाएँ
8. सर्वो डालें और इसे पेंच से ठीक करें
9. कैमरा स्पैसर और यूवीसी कैमरा संलग्न करें, 4x पेंच और नट्स M2 (वैकल्पिक) के साथ फिक्स्ड
10. माउंट टू रोबोट आर्म (वैकल्पिक)

---

<a id="step-4-software-setup-10-minutes"></a>
## चरण 4: सॉफ़्टवेयर सेटअप (10 मिनट)

1. **स्थापित करें STServo एसडीके**
   ```bash
   git clone https://github.com/FEETECH-RC/STServo_SDK_Python.git
   cd STServo_SDK_Python
   cp -r STservo_sdk /path/to/your/project/
   ```

2. **स्थापित करें Python निर्भरता**
   ```bash
   pip install pyserial
   ```

3. **कनेक्शन कॉन्फ़िगर करें**
   ```python
   DEVICENAME = 'COM7'  # Windows
   # DEVICENAME = '/dev/ttyUSB0'  # Linux
   STS_ID = 1  # Servo ID (use 6 if connected as gripper on SO-ARM101)
   ```

---

<a id="step-5-first-test-5-minutes"></a>
## चरण 5: पहला परीक्षण (5 मिनट)

1. **हार्डवेयर कनेक्ट करें**
   - ग्रिपर सर्वो → सर्वो नंबर 5 पर SO-ARM101 सर्वो बस
   - विद्यमान हाथ नियंत्रक → कंप्यूटर (यूएसबी)
   - स्थापित सर्वो के लिए कॉन्फ़िगर किए गए हाथ बिजली की आपूर्ति का उपयोग करें
   - पकाने की सर्वो आईडी को मेल खाने के लिए सेट करें `STS_ID` और बस में इसे अद्वितीय रखें
   - सीरियल पोर्ट खोलने से पहले अन्य रोबोट नियंत्रण अनुप्रयोगों को बंद करें

2. **बुनियादी परीक्षण चलाएं**
   ```bash
   cd software/python
   python gripper_control.py
   ```

3. **बुनियादी आदेशों की कोशिश करें**
   - प्रवेश करें `45` ग्रिपर खोलने के लिए
   - प्रवेश करें `-45` ग्रिपर बंद करने के लिए
   - प्रवेश करें `0` केंद्र में
   - बाहर निकलने के लिए Enter दबाएँ

<a id="troubleshooting"></a>
## समस्या निवारण

<a id="connection-issues"></a>
### कनेक्शन के मुद्दे
- ✅ डिवाइस प्रबंधक (विंडोज) या `ls /dev/ttyUSB*` (लिनक्स)
- ✅ जांचें कि सर्वो पावर एलईडी चालू है
- ✅ विभिन्न बाउड दरों की कोशिश करें (पूर्वनिर्धारितः 1000000)
- ✅ केबल कनेक्शन की जांच करें

<a id="movement-issues"></a>
### आवागमन के मुद्दे
- ✅ रैक के साथ गियर का जुड़ाव सत्यापित करें
- ✅ यांत्रिक बंधन की जांच करें
- ✅ लोयर्स को रॉड पर स्वतंत्र रूप से स्थानांतरित करने का सुनिश्चित करें
- ✅ सर्वो तापमान (max 60°C) की निगरानी करें

<a id="software-issues"></a>
### सॉफ़्टवेयर समस्याएँ
- ✅ स्थापित करें STServo एसडीके सही
- ✅ चेक Python संस्करण (3.6+)
- ✅ सीरियल पोर्ट परमिशन सत्यापित करेंः `sudo chmod 666 /dev/ttyUSB0` (लिनक्स)
